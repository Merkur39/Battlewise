# Battlewise

A mobile-first, offline-capable web app (PWA) for Valheim that tells you, in two seconds and next to the
game, how to take each creature with your gear. French and English.

## Commands

- `npm run dev` / `npm run build` / `npm run preview`
- `npm run check`: typecheck + lint + format check + tests. Must be green before anything is called done.
- `npm run test:watch`, `npm run test:coverage`
- Game data, from `tools/extract` (Python venv, needs the game installed; see its README):
  `.venv/Scripts/python extract_combat.py` regenerates `src/data/game.json`;
  `.venv/Scripts/python -m unittest discover -s tests -v`.

## Layout

- `src/combat/`: pure combat engine (no DOM, no React), tested under node (`core` Vitest project).
- `src/data/`: `game.json`, generated by `tools/extract` and committed (never edited by hand), its types
  and `game` (`src/data/index.ts`); `game.test.ts` checks it against the engine.
- `src/app/`, `src/features/*`, `src/ui/`, `src/i18n/`: interface, tested under jsdom (`ui` project,
  setup in `test/setup.ts`).
- `api/feedback.ts`: the Vercel function that turns a report from the app into an issue, as a GitHub
  App; self-contained (Vercel builds it alone), tested under node (`api` project). Its setup, done once
  by the repository's owner, is in `api/README.md`.
- `tools/extract/`: read-only extraction of the game data (UnityPy for the assets, the decompiled game
  code for the rules); `curation.json` holds only what the game does not carry: which creatures to list,
  their variants, the ignored ones and why, the attack names the game lacks, the body parts its weak spots
  sit on, the biome a creature comes from when a biome lists it beside another of the same name. Game data and code prevail
  over the wiki.
- `src/styles/themes.css`: the seven palettes of the design canvas (16 tokens each), Origine by default,
  others via `data-theme` on `:root`.
- `design/`: the validated mockups (Claude Design canvas) and their tooling; see `design/README.md`. Not
  part of the app's toolchain (ignored by ESLint and Prettier).

## Rules

- Everything in the repository and on GitHub is in English: code, docs, commit messages (Conventional
  Commits), branch names, issues, pull requests and the board. This overrides any preference for French
  commits or pull requests; pull request descriptions keep their usual sections, titled Context,
  Diagnosis and Changes. The conversation stays in French.
- Every pull request that changes the app bumps `version` in `package.json` (`feat` → minor, `fix` →
  patch): Vercel deploys `main` to production on every merge.
- The design canvas is the reference for tokens, components and copy.
- Colours: ok / warn / bad are for verdicts only; accent is for selection and actions. Damage types and
  weaknesses stay neutral.
- French UI says « VD », never « défense ».
- Game names (creatures, items, biomes, damage types, modifier states) come from the game's own
  localisation, in both languages, never translated by hand. The game names no monster attack, except
  those made with a player's weapon, which take its name: the others live in `curation.json`, from the
  Valheim wiki where it has them, otherwise written by hand, each with its source. The app ships numbers and names only, no game art.
