B · Seul l'écran cassé, le reste vit — retenue

Chaque écran a son filet : s'il plante, sa place montre « Cette fiche a planté », Réessayer et « Envoyer le rapport » ; l'en-tête et la navigation restent, le joueur peut changer de monstre ou d'écran. Le rapport est la feuille de signalement de l'app, Bug choisi, l'erreur et sa pile dans ce qui est joint ; même file hors ligne, même accusé. Si c'est le cadre de l'app qui casse, la page de la piste A prend le relais.

Pour : le joueur garde tout le reste, à côté du jeu ; rien de nouveau à apprendre, la feuille et sa file existent déjà. Contre : deux filets à tenir (l'écran et le cadre) ; Réessayer peut replanter, la carte revient alors. EN : « This sheet crashed », « The rest of Foelore works: pick another creature, or go to the Simulation. », « Try again », « Send the report ».
