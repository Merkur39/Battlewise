C · Redémarrer d'abord, proposer ensuite

Quand Foelore plante, l'app redémarre d'elle-même sur le Bestiaire et garde l'erreur sur l'appareil. Un bandeau, en haut, le dit et propose « Envoyer le rapport », qui ouvre la feuille de signalement, Bug choisi, avec l'erreur d'avant le redémarrage ; la croix l'oublie. Si l'app replante dès l'ouverture, elle s'arrête sur une page « Foelore ne démarre plus ».

Pour : le joueur retrouve l'app sans rien toucher, le rapport n'interrompt jamais. Contre : le redémarrage perd l'écran où il était et peut cacher ce qui s'est passé ; il faut garder l'erreur sur l'appareil et compter les plantages au démarrage ; une page de plus pour ce cas. EN : « Foelore crashed and restarted. », « Send the report », « Foelore no longer starts », « Try again ».
