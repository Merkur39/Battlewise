A · Une feuille au premier lancement

Au premier lancement, une feuille du bas s'ouvre sur le Bestiaire : ce que fait Battlewise en une phrase, puis Ton équipement et Ton monde comme dans la feuille « Ton contexte », marqués « personnage neuf ». Chaque rangée ouvre son dialogue ; après Valider, la feuille revient avec la rangée réglée. Sur desktop, le même contenu dans un dialogue de 600 px, la barre latérale derrière.

Pour : une seule interruption, courte ; dit pourquoi les verdicts sont durs ; aucun écran nouveau, les deux dialogues existants servent tels quels ; place naturelle pour l'installation de #49 plus tard. Contre : interrompt la toute première ouverture ; « Plus tard » et rien ne le rappelle. EN : « Before your first creature », « New character », « Set my gear », « Later », « Set », « Let's go ».
