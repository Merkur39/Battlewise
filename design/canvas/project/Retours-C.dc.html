C · Un point, sans interrompre

Rien ne s'ouvre seul. Quand un signalement du joueur est corrigé, un point se pose sur l'icône de Réglages (et sur Réglages dans la barre latérale du desktop). Réglages s'ouvre alors sur la nouvelle, en tête, au-dessus de Mes signalements où la ligne corrigée porte « nouveau » ; le point s'efface une fois vu. À propos montre la dernière version en clair, les précédentes derrière un lien.

Pour : ne coupe jamais une partie, le joueur vient quand il veut. Contre : un point se rate, et le merci, moins visible, porte moins. EN : « New: your report #48 is fixed in 1.5.0. Thank you! », « new », « All versions ».
