# Battlewise

A mobile-first web app that works offline (PWA) and tells you, in two seconds and next to the game,
how to take each creature with your gear: whether to block, parry or dodge each of its attacks, and
what it costs you. In French and English.

Open it at [battlewise.vercel.app](https://battlewise.vercel.app) and install it from the browser, on a
phone or a desktop. Work is tracked on the [Battlewise board](https://github.com/users/Merkur39/projects/4).

## What it does

It starts from the creature, not from a number: in the game, you never see how much an attack deals.

- **Bestiary**: the creatures of each biome, their weaknesses and resistances, and a block, parry and
  dodge verdict on every attack, with your gear.
- **Simulation**: pick a monster's attack, set its stars and your stagger bar, and see what blocking
  and parrying cost you.
- **Arsenal**: shields and weapons compared at your skill level.
- **Guide**: the combat rules, in short.

## Requirements

- Node.js ≥ 22.12.
- To regenerate the game data only: a local Valheim install, Python 3.12 and the .NET 10 SDK, see
  [tools/extract](tools/extract/README.md).

## Commands

```bash
npm install
npm run dev       # dev server
npm run build     # production build in dist/
npm run preview   # serves the build
npm run check     # typecheck, lint, format check and tests
```

`npm run test:watch` and `npm run test:coverage` run the tests alone.

## Releases

Vercel builds this repository: every merge on `main` goes to production, every pull request gets a
preview. Every pull request that changes the app bumps the version in `package.json` (`feat` → minor,
`fix` → patch); Settings › About shows it, and an installed app takes the new version on its own.

## Layout

| Path                      | Contents                                                                       |
| ------------------------- | ------------------------------------------------------------------------------ |
| `src/combat/`             | Pure combat engine: no DOM, no React.                                          |
| `src/data/`               | `game.json`, generated by `tools/extract` and committed, and its types.        |
| `src/app/`, `src/styles/` | Interface and its seven themes.                                                |
| `tools/extract/`          | Read-only extraction of the game data: [README](tools/extract/README.md).      |
| `design/`                 | Working copy of the design canvas and its tooling: [README](design/README.md). |

The project rules (design reference, colours, game names) live in [CLAUDE.md](CLAUDE.md).

## Game data

Creatures, attacks, items, biomes and their French and English names come from the game's own data
and localisation, read from a local install, and `src/data/game.json` is never edited by hand. The
game names no monster attack, except those made with a player's weapon: the other names live in
`tools/extract/curation.json`, each with its source. The app ships numbers and names only, no game
art, and the decompiled game code used to check the rules is never committed.
